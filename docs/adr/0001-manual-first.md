# ADR 0001：先手工验证决策协议

状态：proposed-for-adoption。

## 情境

当前最重要的不确定性是方法和评估是否有用，不是模型调用吞吐。尚无真实对照结果，复杂编排可能让实验条件更难控制。

## 决定

采用 Git + Markdown/JSON + 单个 Python 辅助脚本。唯一第三方运行依赖为 jsonschema；CLI、日志和测试用标准库。暂不增加数据库、Web UI、模型 SDK、多 Agent 或 RAG。

## 后果

好处是本地可读、易审查、无需付费模型接口即可准备材料。代价是操作员需手工搬运题面、保存回复和评分，脚本不识别自然语言问题也不提供系统隔离。

## 验证与复核

先完整跑通一条三阶段轨迹；若记录搬运或版本错误成为重复问题，再考虑单一模型适配器。只有评分准则稳定后，才研究自动辅助评审。

这是提供给 James 的初始建议，不把生成本文件视为已取得最终批准。
