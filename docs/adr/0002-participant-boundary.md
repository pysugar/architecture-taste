# ADR 0002：作者材料与参评题面分离

状态：proposed-for-adoption。

## 情境

案例作者需要保存隐藏事实、后续阶段与评审笔记，参评 Agent 不应取得这些材料。同仓库文件权限加自然语言禁令不能证明隔离。

## 决定

脚本仅允许导出到作者仓库以外，按白名单生成当前阶段题面与该组实际历史。记录输入哈希，不覆盖已有试验目录。最初采用手工文本会话，不声称实现了 OS 沙箱。

## 后果

减少意外披露和错误串接，但不能防止有广泛文件权限的 Agent 读作者目录、兄弟试验或全局记忆；SHA-256 也不是抗恶意篡改机制。

## 验证与复核

测试确保未输出 reviewer、未披露的 oracle 和未来阶段；真正接入可读文件的 Agent 前，另行实施并检验只挂载 participant packet 的运行边界。未检验时标为探索实验，不对外发布严格评测结论。
